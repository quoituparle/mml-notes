Chapter 2 · Linear Algebra

The language of machine learning: data are vectors, models are matrices.

Why this chapter?

Machine learning is mostly "put numbers in a list, multiply by a grid of numbers, look at the result". Linear algebra is the rulebook for that. If you only remember one thing: a matrix is a machine that moves vectors around. Everything here builds on that idea.

In ML you say…In linear algebra that is…

A whole datasetA matrix, one row per example
A linear layer in a neural net$W\mathbf{x}+\mathbf{b}$: a matrix times a vector, plus a shift
Fitting a line to dataSolving $A\mathbf{x}=\mathbf{b}$ as well as possible

2.1Systems of Linear Equations

Let's start with a tiny factory (the book uses a bigger one, the idea is the same). It makes two products and has two limited resources:

  • Product A needs 2 kg wood and 1 h labour. Product B needs 1 kg wood and 3 h labour.
  • We have exactly 5 kg wood and 5 h labour to use up. How many of each, $x_1$ and $x_2$?
$$\begin{aligned}2x_1+x_2&=5 &&\text{(wood)}\\ x_1+3x_2&=5&&\text{(labour)}\end{aligned}\qquad\Longleftrightarrow\qquad \underbrace{\begin{bmatrix}2&1\\1&3\end{bmatrix}}_{A}\underbrace{\begin{bmatrix}x_1\\x_2\end{bmatrix}}_{\mathbf{x}}=\underbrace{\begin{bmatrix}5\\5\end{bmatrix}}_{\mathbf{b}}$$

That compact form $A\mathbf{x}=\mathbf{b}$ is a system of linear equations, with $A\in\mathbb{R}^{m\times n}$ ($m$ equations, $n$ unknowns). You can look at the very same system in two different ways.

View 1: rows. Each equation is a line.

Each equation draws a line in the $(x_1,x_2)$ plane. A solution has to satisfy both, so it is where the lines cross.

Two lines can only cross once, never cross (parallel), or lie on top of each other. So the answer is always 0, 1, or infinitely many solutions. Never exactly two. (Try it. It is oddly satisfying.)

View 2: columns. Mix the columns to hit $\mathbf{b}$.

Write the same system as $x_1\mathbf{a}_1+x_2\mathbf{a}_2=\mathbf{b}$, where $\mathbf{a}_1,\mathbf{a}_2$ are the columns of $A$. Now the question is: how much of each column vector do I need to add up to reach $\mathbf{b}$? This is the view that matters most for ML.

Slide $x_1$ and $x_2$ until the red dot lands on the orange target. Then try the "Dependent columns" presets: when the columns point in the same direction, many targets are simply unreachable. That is exactly the "no solution" case in the row view.

In short. $A\mathbf{x}=\mathbf{b}$ can be read as "lines that meet" or as "a recipe of columns". Solutions: 0, 1, or ∞.
Check yourselfThe system $x_1+x_2=3$, $2x_1+2x_2=6$: how many solutions?
Answer: infinitely many. The second equation is the first one doubled, so both describe the same line.

2.2Matrices

A matrix is a rectangular grid of numbers: $m$ rows, $n$ columns, written $A\in\mathbb{R}^{m\times n}$. A vector is just a matrix with one column.

Multiplying matrices

$AB$ only exists if the inner sizes match: an $(m\times n)$ times an $(n\times k)$ gives an $(m\times k)$. Each entry is a row of $A$ "dotted" with a column of $B$: multiply pairwise, then add.

$$(AB)_{ij}=\sum_{l=1}^{n}a_{il}\,b_{lj}$$
Hover (or tap) a result cell:

Not commutative. Even when both $AB$ and $BA$ exist, usually $AB\neq BA$. Order matters, like putting on socks and then shoes. You'll see a picture of this in 2.7.

Four special characters

NameDefinitionMeaning
Identity $I_n$1s on the diagonal, 0 elsewhereThe "do nothing" matrix: $IA=AI=A$
Inverse $A^{-1}$$AA^{-1}=A^{-1}A=I$The "undo" matrix. Only some square matrices have one (they are called regular or invertible)
Transpose $A^\top$$(A^\top)_{ij}=A_{ji}$Flip over the diagonal: rows become columns
Symmetric$A=A^\top$Mirror-symmetric across the diagonal
$$(AB)^{-1}=B^{-1}A^{-1},\qquad (AB)^\top=B^\top A^\top$$

Why the order flips: to undo "socks then shoes" you must take off the shoes first.

Other rules work as you expect: $A(BC)=(AB)C$ (associative), $A(B+C)=AB+AC$ (distributive), and $(A+B)^\top=A^\top+B^\top$.

In short. Multiply = row · column. Order matters. Inverse = undo. Transpose = flip. Reverse the order when inverting or transposing a product.
Check yourself$A$ is $3\times 2$ and $B$ is $2\times 5$. What is the size of $AB$? Does $BA$ exist?
Answer: $AB$ is $3\times5$. $BA$ would need $5=3$, so it does not exist.

2.3Solving Systems of Linear Equations

How do we actually find $\mathbf{x}$? The classic method is Gaussian elimination: write the system as an augmented matrix $[A\,|\,\mathbf{b}]$ and use three harmless moves on rows until it is easy to read:

  1. swap two rows, 2. multiply a row by a nonzero number, 3. add a multiple of one row to another.

These moves never change the solutions, they just make the equations simpler. The goal is a staircase shape (row-echelon form): the first nonzero number in each row, called the pivot, sits to the right of the pivot above it. Keep going until each pivot is 1 and has zeros above and below it, and you get reduced row-echelon form, where the answer is just written out.

Step through it yourself. The system:

What the end result tells you

  • Pivot columns ↔ basic variables, fixed by the equations. Other columns ↔ free variables, which you can choose freely.
  • A row like $0=1$ → no solution. No free variables → exactly one. Free variables left → infinitely many.

With free variables the solution set has a neat structure: one particular solution plus anything from the kernel (solutions of $A\mathbf{x}=\mathbf 0$).

$$\{\mathbf{x}:A\mathbf{x}=\mathbf{b}\}=\mathbf{x}_p+\{\mathbf{x}:A\mathbf{x}=\mathbf{0}\}$$

Minus-1 trick (from the book): in the reduced form of the "Infinitely many" example, read off the particular solution $\mathbf{x}_p=(3,0,1)$ from the pivot rows. For the kernel, take each non-pivot column and write it with a $-1$ in the free variable's slot: $(2,-1,0)$. So all solutions are $(3,0,1)+\lambda(2,-1,0)$. Check it in the original equations.

Computing an inverse

Same trick: row-reduce $[A\,|\,I]$ until the left side becomes $I$, and the right side becomes $A^{-1}$.

When $A$ is not square

In ML you usually have more equations than unknowns (many data points, few parameters), so an exact solution rarely exists. If $A$ has linearly independent columns, you can instead use the Moore–Penrose pseudo-inverse:

$$A\mathbf{x}=\mathbf{b}\ \Longleftrightarrow\ A^\top A\mathbf{x}=A^\top\mathbf{b}\ \Longleftrightarrow\ \mathbf{x}=(A^\top A)^{-1}A^\top\mathbf{b}$$
ML link. This is the closed-form solution of linear regression (Ch. 9): the best-fitting $\mathbf{x}$ in the least-squares sense. The book also warns that explicitly computing inverses is numerically fragile and expensive, so real software uses smarter factorisations (Ch. 4).
In short. Gaussian elimination = clean up rows with 3 safe moves. Pivots decide unique / none / infinite. Solutions = particular + kernel.
Check yourselfAfter elimination a 3-unknown system has 2 pivots and no contradictory row. How many free variables, and how many solutions?
Answer: $3-2=1$ free variable, so infinitely many solutions (a line of them).

2.4Vector Spaces

So far "vector" meant a list of numbers. Mathematicians zoom out: a vector space is any collection of things you can add and scale without ever leaving the collection. Lists of numbers qualify, but so do matrices and even functions.

Groups (the warm-up)

DefGroup

A set $G$ with an operation $\otimes$ is a group if it has closure (combining two members gives a member), associativity, a neutral element $e$ (changes nothing), and an inverse for each element. If $x\otimes y=y\otimes x$ always, the group is Abelian.

Examples: whole numbers with $+$ form an Abelian group. Invertible matrices with multiplication form a group too, the general linear group $GL(n,\mathbb{R})$, but it is not Abelian (matrix order matters!).

DefVector space

A set $V$ with addition $+$ (making $(V,+)$ an Abelian group) and scaling by real numbers $\lambda\cdot\mathbf{x}$, obeying the usual distributive and associative rules, and $1\cdot\mathbf{x}=\mathbf{x}$.

Translation: if you add two members or stretch one, you stay in the set. Examples: $\mathbb{R}^n$, matrices $\mathbb{R}^{m\times n}$, polynomials.

DefVector subspace

A subset $U\subseteq V$ that is itself a vector space. In practice: it contains $\mathbf{0}$, and it is closed under addition and scaling.

Test closure here. Pick two points $u,v$ on the curve and see where $u+v$ and $2u$ land.

Lines and planes through the origin are subspaces. Shift the line off the origin, or bend it, and it breaks. Also: the kernel $\{\mathbf{x}:A\mathbf{x}=\mathbf{0}\}$ is always a subspace, but $\{\mathbf{x}:A\mathbf{x}=\mathbf{b}\}$ with $\mathbf b\neq\mathbf 0$ is not (it misses $\mathbf{0}$).

In short. Vector space = closed under add and scale. Subspace = a vector space sitting inside another. It must pass through $\mathbf{0}$.
Check yourselfIs the set of all points with $x_1\ge 0$ in $\mathbb{R}^2$ a subspace?
Answer: No. It has $\mathbf 0$ and is closed under addition, but multiplying $(1,0)$ by $-1$ leaves the set.

2.5Linear Independence

A linear combination of vectors is a sum of stretched copies: $\lambda_1\mathbf{x}_1+\dots+\lambda_k\mathbf{x}_k$. The set of everything you can reach this way is their span.

Vectors are linearly independent if each one adds a genuinely new direction. Formally, the only way to combine them into $\mathbf{0}$ is the boring way, with every $\lambda_i=0$:

$$\lambda_1\mathbf{x}_1+\dots+\lambda_k\mathbf{x}_k=\mathbf{0}\ \Longrightarrow\ \lambda_1=\dots=\lambda_k=0$$

If a non-boring combination gives $\mathbf 0$, the vectors are dependent, meaning one of them is redundant (a combination of the others).

How to test it: put the vectors as columns of a matrix and run Gaussian elimination. If every column is a pivot column, they are independent. Any column without a pivot is redundant.

ML link. Two features that are perfect copies of each other (height in cm and height in inches) are linearly dependent. They carry no extra information and can make a regression ill-defined, since the matrix $A^\top A$ from 2.3 stops being invertible.
In short. Independent = no redundant vectors. Dependent = someone can be built from the others.
Check yourselfAre $(1,2)$, $(2,4)$ independent? And any three vectors in $\mathbb{R}^2$?
Answer: The first pair is dependent ($(2,4)=2\cdot(1,2)$). Any three vectors in $\mathbb{R}^2$ are dependent: the plane only has 2 directions to offer.

2.6Basis and Rank

Basis: the smallest set that covers everything

A basis of a vector space is a set of independent vectors whose span is the entire space: no gaps, no waste. Every basis of a space has the same size, called its dimension. ($\mathbb{R}^2$ has dimension 2, whichever basis you pick.)

Given a basis, every vector has unique coordinates: exactly one way to write $\mathbf{x}=\alpha_1\mathbf{b}_1+\dots+\alpha_n\mathbf{b}_n$. Change the basis and the coordinates change, but the point stays put:

The red point never moves. Only the grid (orange) changes. "Basis" is just which ruler you measure with. The standard basis $\mathbf{e}_1,\mathbf{e}_2$ is merely the most common ruler.

Rank: how much information is really in a matrix

The rank of a matrix, $\operatorname{rk}(A)$, is its number of linearly independent columns (which is always equal to the number of independent rows). Facts worth remembering:

  • $\operatorname{rk}(A)=\operatorname{rk}(A^\top)$
  • A square $n\times n$ matrix is invertible ⇔ $\operatorname{rk}(A)=n$ (full rank)
  • $A\mathbf{x}=\mathbf{b}$ has a solution ⇔ $\operatorname{rk}(A)=\operatorname{rk}([A\,|\,\mathbf{b}])$
  • Rank in an $m\times n$ matrix is at most $\min(m,n)$. If lower, the matrix is rank-deficient.
Rank explorer. Type numbers into the matrix (or use a preset):
ML link. Low rank = compressible. A big data matrix with small rank can be stored with far fewer numbers (that is the idea behind PCA and SVD in Ch. 4 and 10).
In short. Basis = independent vectors that span the space; their count is the dimension. Rank = number of independent columns; full rank = invertible.
Check yourselfA $4\times 4$ matrix has rank 3. Is it invertible?
Answer: No. Invertible needs rank 4. One column is a mix of the others.

2.7Linear Mappings

Now the big idea. A linear mapping $\Phi:V\to W$ is a function that respects the structure of vector spaces:

$$\Phi(\mathbf{x}+\mathbf{y})=\Phi(\mathbf{x})+\Phi(\mathbf{y}),\qquad \Phi(\lambda\mathbf{x})=\lambda\,\Phi(\mathbf{x})$$

Pictures: grid lines stay straight and parallel, the origin stays put, evenly spaced points stay evenly spaced. Vocabulary: injective (no two inputs collide), surjective (every output is hit), bijective (both, so it can be undone).

Matrices are linear maps

Every matrix defines one: $\mathbf{x}\mapsto A\mathbf{x}$. And once you fix bases, every linear map between finite-dimensional spaces is a matrix. The recipe for the transformation matrix is delightfully simple: column $j$ = where basis vector $\mathbf{b}_j$ lands.

$$\Phi(\mathbf{b}_j)=\sum_{i=1}^m\alpha_{ij}\mathbf{c}_i\quad\Longrightarrow\quad A_\Phi=[\alpha_{ij}]$$

Drag the sliders: the blue and green arrows are the two columns of $A$. The unit square gets carried along and its area is multiplied by $|\det A|$.

Doing two maps in a row

Applying $B$ then $A$ is the single map $AB$. And since matrix multiplication is not commutative, the order of transformations matters:

Same map, different basis

ThmBasis change

If we swap the basis of $V$ (via matrix $S$) and of $W$ (via $T$), the matrix of $\Phi$ becomes

$$\tilde A_\Phi=T^{-1}A_\Phi S$$

Read it right to left: convert coordinates into the old basis ($S$), apply the map ($A_\Phi$), convert the result to the new basis ($T^{-1}$). If $V=W$ this is $S^{-1}AS$ and the matrices are called similar. Chapter 4 uses this to find a basis in which a matrix becomes diagonal (very easy).

Image and kernel

DefKernel and image

$$\ker(\Phi)=\{\mathbf{x}:\Phi(\mathbf{x})=\mathbf 0\},\qquad \operatorname{Im}(\Phi)=\{\Phi(\mathbf{x}):\mathbf{x}\in V\}$$

Kernel = everything the map crushes to zero. Image = everything the map can produce. They trade off:

$$\dim\ker(\Phi)+\dim\operatorname{Im}(\Phi)=\dim V\qquad\text{(rank–nullity)}$$

Try the Squash (singular) preset above. The plane collapses onto a line: image has dimension 1, so the kernel must have dimension $2-1=1$ (a whole line of points gets crushed to the origin). A map is injective exactly when its kernel is just $\{\mathbf 0\}$. And $\operatorname{rk}(A)=\dim\operatorname{Im}(A)$.

In short. Matrix = linear map; columns = where the basis vectors go. Compose = multiply (order matters). Kernel + image dimensions add to the input dimension.
Check yourselfA $5\times 3$ matrix has rank 3. What is its kernel?
Answer: Rank–nullity: $\dim\ker=3-3=0$, so the kernel is just $\{\mathbf 0\}$ and the map is injective.

2.8Affine Spaces

Subspaces must pass through the origin. What about a line that doesn't? That is an affine subspace: a subspace $U$ shifted by a support point $\mathbf{x}_0$.

$$L=\mathbf{x}_0+U=\{\mathbf{x}_0+\mathbf{u}:\mathbf{u}\in U\}$$

And an affine mapping is a linear map followed by a translation: $\phi(\mathbf{x})=\mathbf{a}+\Phi(\mathbf{x})$.

This ties the chapter together. The solutions of $A\mathbf{x}=\mathbf{b}$ are exactly an affine subspace: particular solution + kernel (see 2.3). Here is a single equation $ax_1+bx_2=c$:

ML link. Every neural-network layer $\mathbf{x}\mapsto W\mathbf{x}+\mathbf{b}$ is an affine map. The matrix $W$ rotates/stretches/squashes, the bias $\mathbf{b}$ shifts.
In short. Affine = linear + shift. Solutions to $A\mathbf{x}=\mathbf{b}$ form an affine subspace.
Check yourselfIs $\{(x,y):x+y=1\}$ a subspace? An affine subspace?
Answer: Not a subspace (it misses $(0,0)$). It is affine: the line $x+y=0$ shifted by $(1,0)$.
